# بازی کیان پوری — نسخه وب

این پوشه، نسخه‌ی کاملاً وب (HTML/CSS/JavaScript + یک سرور Node.js ساده) از بازی اصلی شماست که با Pygame نوشته شده بود.
منطق بازی (پرش، خم شدن، موانع، سکه‌ها، سپر، امتیاز، مراحل ۲۰ و ۵۰، حمایت مالی، مکث، باخت) کاملاً بازسازی شده و طوری ساخته شده که:

- روی مرورگر (دسکتاپ و موبایل) اجرا می‌شود، بدون نیاز به نصب پایتون یا هیچ برنامه‌ای.
- به‌صورت خودکار تشخیص می‌دهد کاربر روی گوشی است یا کامپیوتر و اندازه‌ی فونت‌ها/دکمه‌ها را برای لمس با انگشت بزرگ‌تر می‌کند و کنترل‌های لمسی (دکمه‌ی پرش و خم‌شدن) نشان می‌دهد.
- روی Railway با یک کلیک بالا می‌آید و با دامنه‌ی شخصی شما کار می‌کند.

## چه چیزهایی تغییر کرده؟ (رفع باگ)

1. **باگ موسیقی صفحه‌ی باخت**: در نسخه‌ی اصلی، در صفحه‌ی «باختی!» موسیقی هر فریم (۶۰ بار در ثانیه) قطع و دوباره از اول پخش می‌شد که باعث می‌شد صدا قطع‌وصل/خراب به نظر برسد. در نسخه‌ی وب این مشکل رفع شده: صدای باخت فقط یک‌بار پخش می‌شود.
2. **پاپ‌آپ‌های مرحله‌ی ۲۰ و ۵۰**: در نسخه‌ی دسکتاپ این پاپ‌آپ‌ها با Tkinter کل بازی را قفل می‌کردند. در وب این‌ها به یک کارت شیک داخل خود بازی تبدیل شده‌اند که بازی را متوقف می‌کند تا کاربر «ادامه» را بزند، بدون قفل‌شدن مرورگر.
3. **امتیاز برتر (High Score)**: چون نسخه‌ی وب روی مرورگر هر کاربر اجرا می‌شود (نه یک فایل روی هارد شما)، امتیاز برتر در `localStorage` مرورگر ذخیره می‌شود؛ یعنی هر کاربر امتیاز برتر خودش را می‌بیند.
4. کارت حمایت مالی و شماره کارت (`6104 3375 1296 9740`) عیناً از نسخه‌ی اصلی شما آورده شده و با یک لمس/کلیک کپی می‌شود.

## اجرای محلی (تست قبل از آپلود)

نیاز به Node.js نسخه ۱۸ به بالا دارید (چیز دیگری لازم نیست، بدون هیچ پکیج خارجی):

```bash
node server.js
```

سپس در مرورگر بروید به: `http://localhost:3000`

## آپلود در گیت‌هاب

1. یک ریپوی جدید در گیت‌هاب بسازید (مثلاً `kianpori-game-web`).
2. تمام محتوای همین پوشه (`KianporGame-Web`) را در آن ریپو قرار دهید و پوش کنید:

```bash
git init
git add .
git commit -m "Kianpori Game - web edition"
git branch -M main
git remote add origin https://github.com/USERNAME/kianpori-game-web.git
git push -u origin main
```

## دیپلوی روی Railway

1. وارد [railway.app](https://railway.app) شوید.
2. **New Project → Deploy from GitHub repo** را بزنید و ریپویی که ساختید را انتخاب کنید.
3. Railway به‌صورت خودکار Node.js را تشخیص می‌دهد و دستور `npm start` (که همان `node server.js` است) را اجرا می‌کند. نیازی به تنظیم دستی متغیر `PORT` نیست؛ Railway خودش آن را می‌فرستد و کد آن را می‌خواند.
4. بعد از دیپلوی، یک دامنه‌ی موقت `xxx.up.railway.app` می‌گیرید که می‌توانید همان‌جا بازی را تست کنید.

## وصل کردن دامنه‌ی شخصی‌تان

1. در پنل پروژه روی Railway، به تب **Settings → Networking → Custom Domain** بروید.
2. دامنه‌ی خودتان را وارد کنید (مثلاً `game.example.com` یا خودِ `example.com`).
3. Railway یک رکورد **CNAME** (یا برای دامنه‌ی ریشه، یک رکورد که خودش راهنمایی می‌کند) به شما می‌دهد.
4. آن رکورد را در پنل مدیریت DNS دامنه‌تان (جایی که دامنه را خریده‌اید) اضافه کنید.
5. بعد از چند دقیقه تا چند ساعت (بسته به انتشار DNS)، با زدن دامنه‌ی خودتان مستقیم بازی بالا می‌آید.

## ساختار پروژه

```
KianporGame-Web/
├── package.json        # تعریف پروژه‌ی Node (بدون هیچ وابستگی خارجی)
├── server.js           # سرور استاتیک ساده که فایل‌های public را سرو می‌کند
├── public/
│   ├── index.html      # صفحه‌ی اصلی
│   ├── style.css        # استایل‌ها + واکنش‌گرایی موبایل/دسکتاپ
│   ├── game.js          # کل منطق بازی (نسخه‌ی جاوااسکریپتی Pygame شما)
│   └── assets/
│       ├── images/      # همان عکس‌های اصلی بازی
│       └── audio/       # همان صداهای اصلی بازی
└── README.md
```

## نکات فنی موبایل

- بازی روی یک بومِ (canvas) با اندازه‌ی ثابت داخلی طراحی شده و با CSS خودش را با حفظ نسبت تصویر، با هر اندازه صفحه (گوشی/تبلت/دسکتاپ) تطبیق می‌دهد.
- وقتی مرورگر روی گوشی یا صفحه‌ی لمسی تشخیص داده شود، دکمه‌ها و فونت‌های منو/پاپ‌آپ‌ها بزرگ‌تر رسم می‌شوند تا لمس با انگشت راحت باشد، و دو دکمه‌ی لمسی «پرش» و «خم شو» زیر بازی نمایش داده می‌شوند.
- به‌خاطر محدودیت مرورگرها، صدا فقط بعد از اولین لمس/کلیک کاربر پخش می‌شود (همان صفحه‌ی شروعی که می‌بینید).

اگر خواستید بعداً دیتابیس واقعی (مثلاً برای امتیاز برتر مشترک بین همه‌ی بازیکن‌ها) اضافه شود یا ظاهر بازی تغییر کند، بگویید تا اضافه کنم.
